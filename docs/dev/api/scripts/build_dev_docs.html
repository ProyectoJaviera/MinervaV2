scripts.build_dev_docs

Genera la referencia de la API interna (pdoc) y los hechos de las guias de docs/dev/.

Hace tres cosas, todas derivadas del codigo:

  1. Referencia HTML de todos los modulos publicos de app/ y scripts/ con pdoc en docs/dev/api/ (abrir docs/dev/api/index.html en un navegador; no necesita red). Los docstrings siguen el formato de Google (Args:, Returns:, Raises:) mas la seccion propia Efectos:; tests/unit/test_docstrings.py exige que todo lo publico los tenga.
  2. Hechos de las guias docs/dev/modulos/*.md: entre las marcas <!-- hechos:RUTA --> y <!-- /hechos:RUTA --> de cada archivo escribe sus imports, la configuracion que lee, las tablas que toca y las pruebas que lo importan (scripts/dev_docs_facts.py). La narrativa es a mano.

  3. Grafo de paquetes (Mermaid y tabla) en docs/dev/README.md, entre <!-- grafo-paquetes --> y <!-- /grafo-paquetes -->.

    python scripts/build_dev_docs.py # regenera lo que este desactualizado python scripts/build_dev_docs.py --force # regenera tambien la referencia pdoc python scripts/build_dev_docs.py --check # solo verifica (sale con 1 si hay algo viejo) python scripts/build_dev_docs.py --check --strict # ademas regenera en una carpeta temporal

Como sabe que la referencia esta vieja. docs/dev/api/manifest.json guarda, por cada archivo de app/ y scripts/, la huella de su SUPERFICIE DOCUMENTADA (documentation_surface): firmas, docstrings, constantes y atributos, sin los cuerpos de las funciones. Cambiar la logica de una funcion no pide regenerar; cambiar una firma, un docstring o una constante, si. El manifiesto tambien guarda la huella de cada pagina HTML, para detectar paginas editadas a mano o a medias. Con --strict (y solo si pdoc, Python y sistema operativo son los del manifiesto) se regenera todo en una carpeta temporal y se compara pagina por pagina.

Seguridad. pdoc IMPORTA los modulos para leerlos. Para que eso no lea secretos ni deje rastros: corre en un proceso aparte (--worker) con el directorio de trabajo en una carpeta temporal vacia (asi Settings() no encuentra ningun .env), con las variables de entorno de .env.example quitadas, con os.chdir anulado (varios scripts lo llaman al importarse) y ocultando settings. Despues reemplaza las rutas locales por <repo> y se niega a publicar una pagina que aun muestre una ruta de la carpeta personal. PYTHONHASHSEED=0 fija el orden de los frozenset, que pdoc imprime tal cual.

WORKER_TIMEOUT_SECONDS = 900
WORKER_FLAG = 'MINERVA_DOCS_WORKER'
PLACEHOLDER = '&lt;repo&gt;'

WORKER_CWD_PATH = re.compile('(?:[A-Za-z]:|/)[^\'\\"&;<>\\s]*?minerva_docs_cwd_\\w+')
FACTS_MARK = re.compile('(?P<open><!-- hechos:(?P<path>\\S+) -->)\\n(?P<body>.*?)(?P<close><!-- /hechos:(?P=path) -->)', re.DOTALL)
GRAPH_MARK = re.compile('(?P<open><!-- grafo-paquetes -->)\\n(?P<body>.*?)(?P<close><!-- /grafo-paquetes -->)', re.DOTALL)
SECRET_PATTERNS = (('clave de Anthropic', re.compile('sk-ant-[A-Za-z0-9_-]{16,}')), ('hash bcrypt', re.compile('\\$2[aby]\\$\\d\\d\\$[./A-Za-z0-9]{40,}')), ('JWT', re.compile('eyJ[A-Za-z0-9_-]{16,}\\.[A-Za-z0-9_-]{8,}')), ('token de Telegram', re.compile('\\b\\d{8,10}:[A-Za-z0-9_-]{30,}')))
PENDING_TEXT = '_Pendiente de documentar._'
SOURCE_MESSAGES = ('archivo nuevo que no esta en el manifiesto', 'archivo borrado que sigue en el manifiesto', 'superficie documentada cambiada')

def documentation_surface(source: str) -> str:

El texto de lo que pdoc puede mostrar de un archivo, sin los cuerpos de las funciones.

Incluye: el docstring del modulo, las cabeceras (decoradores y firma) y los docstrings de funciones y clases, las asignaciones de modulo y de clase (pdoc imprime sus valores), los imports (de ellos salen los enlaces entre paginas) y las asignaciones self.x = ... de __init__ (pdoc las documenta como atributos). Todo se toma del texto fuente, no de ast.unparse, para que no dependa de la version de Python.

Arguments:
  • source: el codigo fuente del archivo.
Returns:

El texto canonico de la superficie.

Raises:
  • SyntaxError: si el archivo no se puede parsear.
def surface_digest(source: str) -> str:

  • source: el codigo fuente.
Returns:

La huella en hexadecimal.

def api_problems(repo: pathlib.Path, *, strict: bool = False) -> list[str]:

Lo que esta desactualizado en docs/dev/api/; vacio si esta al dia.

La verificacion normal es portable (solo lee archivos): compara la superficie documentada actual con la del manifiesto y las paginas con sus huellas. Con strict regenera ademas la referencia en una carpeta temporal y la compara pagina por pagina, pero solo si pdoc, Python y el sistema operativo son los del manifiesto (si no, lo dice y no compara).

Arguments:
  • repo: raiz del repositorio.
  • strict: regenerar y comparar de verdad.
Returns:

Una descripcion por problema.

Efectos:

Lee fuentes y referencia; con strict, corre pdoc en un proceso aparte y escribe en una carpeta temporal.

def scrubbed_environment(repo: pathlib.Path) -> dict[str, str]:

El entorno del proceso que corre pdoc: sin las variables de .env.example.

Lee SOLO los nombres de .env.example (nunca .env) para quitarlos del entorno heredado, y fija PYTHONHASHSEED=0 (orden estable de los frozenset que pdoc imprime), PYTHONUTF8=1 y PYTHONDONTWRITEBYTECODE=1.

Arguments:
  • repo: raiz del repositorio.
Returns:

El diccionario de entorno para subprocess.run.

Efectos:

Lee .env.example.

def render_reference(output: pathlib.Path) -> None:

Corre pdoc sobre app y scripts EN ESTE proceso; solo lo llama --worker.

Importa los modulos, asi que SOLO corre en el proceso limpio que prepara generate_reference (marca de entorno, directorio de trabajo vacio y distinto del repositorio): si no, se niega ANTES de importar nada, porque Settings() leeria el .env del directorio de trabajo. Ademas anula os.chdir (varios scripts lo llaman al importarse) y reemplaza el repr de Settings: pdoc imprime el valor de settings y, asi, nunca mostraria valores aunque el aislamiento fallara.

Arguments:
  • output: carpeta donde escribir el HTML.
Raises:
  • SystemExit: si no lo lanzo generate_reference.
  • UserWarning: si pdoc avisa de algo (por ejemplo un docstring que no puede interpretar).
Efectos:

Importa todos los modulos de app/ y scripts/; escribe el HTML en output.
