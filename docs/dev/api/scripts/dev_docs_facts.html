scripts.dev_docs_facts

Hechos derivados del codigo para las guias de docs/dev/ (imports, tablas, configuracion).

Las guias por modulo (docs/dev/modulos/*.md) mezclan narrativa escrita a mano con hechos que se pueden calcular leyendo el codigo. Este modulo los calcula con ast (NUNCA importa app ni lee .env) y scripts/build_dev_docs.py los escribe entre las marcas <!-- hechos:RUTA --> y <!-- /hechos:RUTA --> de cada guia; una prueba falla si alguno quedo viejo.

Alcance de cada hecho (se repite en cada guia para que nadie lo lea de mas):

  • Importa / Lo importan: imports internos (app.*, scripts.*), incluidos los perezosos dentro de funciones. Es el grafo de IMPORTS, no el de llamadas.
  • Configuracion: atributos de Settings leidos como settings.X o self._settings.X. No ve los que llegan por getattr ni por otro nombre de variable.
  • Tablas: las del SQL escrito en el archivo y las de las funciones de los repositorios (app/persistence/repositories/) que el archivo llama. No sigue llamadas a otros modulos.
  • Pruebas: archivos de tests/ que importan el modulo o citan su ruta; una prueba que lo ejercita sin importarlo (p. ej. por la API HTTP) no aparece.

Las rutas se escriben siempre con /, relativas a la raiz del repositorio.

@dataclass(frozen=True)
class Source:

Un archivo Python ya leido y parseado.

Attributes:
  • path: ruta relativa a la raiz del repositorio, con /.
  • module: nombre con puntos (app.trading.risk_engine; el paquete para __init__.py).
  • is_package: si es un __init__.py.
  • text: el codigo fuente.
  • tree: su arbol sintactico.

@dataclass(frozen=True)
class Facts:

Los hechos de un archivo, listos para escribirse en una guia.

Attributes:
  • path: ruta del archivo.
  • module: nombre con puntos.
  • imports: modulos internos que importa.
  • imported_by: modulos internos que lo importan.

  • lines: cuantas lineas tiene el archivo.

def module_name(path: str) -> str:

def reference_page(path: str) -> str | None:

La ruta de la pagina pdoc de un archivo, o None si pdoc no lo documenta.

pdoc omite los modulos privados (algun componente del nombre empieza con _).

Arguments:
  • path: ruta relativa del archivo con /.
Returns:

La ruta relativa a docs/dev/api/ (app/trading/risk_engine.html), o None.

def load_sources( repo: pathlib.Path, roots: tuple[str, ...] = ('app', 'scripts')) -> dict[str, Source]:

Lee y parsea todos los .py bajo roots.

Arguments:
  • repo: raiz del repositorio.
  • roots: carpetas a recorrer.
Returns:

Los archivos por ruta, ordenados por ruta.

Efectos:

Lee los archivos .py del repositorio; no ejecuta nada.

def import_bindings( source: Source, known: frozenset[str]) -> tuple[set[str], dict[str, tuple[str, str | None]]]:

Los imports internos de un archivo y los nombres locales que dejan.

Arguments:
  • source: el archivo.
  • known: nombres con puntos de los modulos internos.
Returns:

La tupla (modulos importados, nombres locales). Cada nombre local apunta a (modulo, atributo): el atributo es None si el nombre ES el modulo (from app.persistence.repositories import shadow_repo).

def settings_catalog( sources: dict[str, Source]) -> tuple[dict[str, str], set[str]]:

  • sources: los archivos del repositorio.
Returns:

La tupla (campo -> variable de entorno, nombres de propiedades y metodos publicos). La variable de entorno es el alias del campo, o su nombre en mayusculas.

def settings_used( source: Source, fields: dict[str, str], methods: set[str]) -> set[str]:

La configuracion que un archivo lee (settings.X, self._settings.X, cfg.X).

  • source: el archivo.
  • fields: campo de Settings -> variable de entorno.
  • methods: propiedades y metodos publicos de Settings.
Returns:

Las variables de entorno de los campos leidos y, en minusculas, los nombres de las propiedades. Vacio para app/config.py, que los define.

def sql_access( node: ast.AST, tables: frozenset[str], skip: set[int]) -> Access:

Las tablas que toca el SQL escrito bajo node.

Arguments:
  • node: funcion, clase o modulo a revisar.
  • tables: nombres de tablas validos (lo que no sea una tabla se ignora).
  • skip: ids de los docstrings, que no se miran.
Returns:

Las tablas leidas, escritas y alteradas. Con un nombre de tabla dinamico (FROM {table}) cuenta cada tabla que aparezca como cadena en node.

def render_mermaid(facts: dict[str, Facts]) -> str:

El diagrama Mermaid de dependencias entre paquetes (el filtrado que se explica al pie).

Dibuja solo las flechas con DIAGRAM_MIN_IMPORTS imports o mas; omite las que llegan a los paquetes de base (DIAGRAM_HIDDEN_TARGETS) y las que salen de los que lo ensamblan todo (DIAGRAM_HIDDEN_SOURCES). La tabla completa va aparte (render_dependency_table).

Arguments:
  • facts: los hechos de collect_facts.
Returns:

El bloque de codigo Mermaid, con sus cercas.

def render_dependency_table(facts: dict[str, Facts]) -> str:

La tabla completa de dependencias entre paquetes, con tamanos.

Arguments:
  • facts: los hechos de collect_facts.
Returns:

Una tabla Markdown: paquete, archivos, lineas, de que paquetes importa (con el numero de imports) y quien lo importa.

def render_graph(facts: dict[str, Facts]) -> str:

Returns:
