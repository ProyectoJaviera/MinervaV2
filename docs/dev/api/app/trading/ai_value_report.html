app.trading.ai_value_report

Informe del veredicto de valor de la IA (subfase 3.6, punto de analisis unico de 300 conglomerados efectivos por lado; docs/FASE3_6_LLM.md secciones (i) y (m)).

Solo lectura, sobre una COPIA de la base. Todo entra por un sqlite3.Connection abierto en modo solo lectura (scripts/ai_value_report.py).

Guardia del gate, estructural. build_report empieza con compute_status (consultas SIN PnL) y, si is_measurement_gate_open es falso, devuelve sin haber ejecutado nunca la consulta que lee pnl_*/exit_price/close_reason (_load_outcome_trades). Mirar resultados antes de MIN_EFFECTIVE_N por lado contaminaria el veredicto (seccion i).

Guardia estricta del punto de analisis. El gate de measurement_status no excluye las sombras RECONCILE_FAILED ni las del piloto, pero ai_value_verdict si. Si el gate abre y, tras esas exclusiones, el N efectivo que usaria el veredicto es < MIN_EFFECTIVE_N en algun lado, el informe declara "punto de analisis no alcanzado" y NO muestra ni Δ ni IC ni desglose (ai_value_verdict los devuelve aun con N insuficiente; esta funcion no se modifica, se suprime aqui).

Datos sinteticos. allow_synthetic_for_tests solo se acepta si la base es positivamente sintetica (assert_synthetic_database): todas las filas de llm_logs con model == SYNTHETIC_MODEL y ninguna con el hash congelado real. Una copia de la base real siempre tiene el modelo real y el hash real, asi que la bandera nunca puede destapar resultados reales.

def build_report( conn: sqlite3.Connection, *, frozen_hash: str = '0fa0dd75a3fecdae36f3b77c8b7ec5d97d58a2238349283c61bfa7632188c777', allow_synthetic_for_tests: bool = False) -> ReportResult:

Construye el informe del veredicto con la guardia del gate de forma ESTRUCTURAL.

Empieza con compute_status (sin PnL) y, si el gate esta cerrado, devuelve sin haber ejecutado jamas la consulta que lee resultados. Si el gate abre pero tras excluir sombras no confiables y del piloto el N efectivo limpio es menor que MIN_EFFECTIVE_N, declara "punto de analisis no alcanzado" y NO muestra diferencia, intervalo ni desglose.

Arguments:
  • conn: conexion de solo lectura a una COPIA de la base.
  • frozen_hash: hash del prompt de la medicion; por defecto, el congelado.
  • allow_synthetic_for_tests: acepta otro hash solo con una base positivamente sintetica.
Returns:

El ReportResult.

Raises:
  • ValueError: si el hash no es el congelado y no se pidio el modo sintetico.
  • SyntheticGuardError: si se pidio el modo sintetico y la base no lo es.
Efectos:

Lee llm_logs, shadow_trades y signals; PnL solo con el gate abierto.
